# Промпты для Claude Code

Открыть Claude Code в корне репозитория (модель Opus, режим auto), вставить промпт нужной волны
целиком. Один промпт на сессию. Если сессия оборвалась, промпт «Продолжение».

## Перед промптом (руками, 1 минута)

```bash
git fetch origin
git worktree add ../lct-worktrees/wave-NN -b wave-NN/main origin/main
cd ../lct-worktrees/wave-NN
gh issue edit <номер issue волны> --add-label in_progress
```

Агента открывать уже внутри этого worktree.

## Общий промпт волны (подставить номер волны и номер issue)

```
Ты работаешь в worktree ветки wave-NN/main по issue #<N>.
Прочитай CLAUDE.md, PRD.md, plan/README.md, plan/wave-NN.md и docs/PROGRESS.md.
Если это волна 1 или ты ещё не изучал data/organizers/, изучи все файлы там:
PDF, xlsx, скриншоты открой и посмотри; билеты это скан, поверни страницы и распознай.

Сделай волну NN целиком: все задачи из раздела «Задачи» в указанном порядке.
Пункты с пометкой (P2) делай после остальных и только если основные закрыты.
Не делай ничего из следующих волн, даже если это кажется логичным.

После задач прогони всё из раздела «Проверка», исправь всё красное.
Если что-то не удаётся после трёх разных попыток, запиши в docs/BLOCKERS.md
(что пробовал, текст ошибки) и переходи к следующей задаче волны.
Самостоятельные решения по неясным местам записывай в docs/DECISIONS.md.

В конце обнови docs/PROGRESS.md (волна, что сделано, что осталось, как проверить),
сделай коммиты с сообщениями по-русски и номером issue, запушь ветку и открой
pull request с «Closes #<N>». Остановись. Скажи мне одним абзацем,
что готово к ручной проверке из раздела «Показать» и что не закрыто.
```

## После ручной проверки

Вадим проходит «Показать», при необходимости просит агента доделать в той же ветке, затем мержит
PR (`gh pr merge --squash`), удаляет worktree.

## Продолжение прерванной сессии

```
Прочитай docs/PROGRESS.md, PRD.md и файл текущей волны из plan/.
Проверь, что проверки последней закрытой волны зелёные (scripts/check.sh и тесты волны).
Продолжи текущую волну с того места, где остановились, по общему промпту.
```

## Ручная проверка после волны (для Вадима, не для агента)

1. Пройти раздел «Показать» в браузере, сделать скриншоты в `docs/screenshots/wave-NN/`.
2. Сверить с ТЗ организаторов пункты, которые волна должна закрывать (PRD раздел 14 и матрица).
3. Написать Константину: «волна NN закрыта» или что не так.
4. `git push origin main`.

## Если агент делает не то

- Уходит в следующие волны: «Стоп. Это волна N+1. Вернись к задачам wave-NN.md».
- Ослабляет тесты ради зелёного: «Верни проверку. Лучше красный тест и запись в BLOCKERS.md».
- Тянет внешние сервисы или CDN: «Запрещено PRD раздел 2. Всё локально».
- Переписывает PRD или план: «PRD и план меняют только люди. Предложи изменение в DECISIONS.md».
