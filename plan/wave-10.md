# Волна 10. Аналитика, прогноз, адаптивный подбор

**Срок:** 24.09. **PRD:** раздел 9.7, 13.7 (аналитика).

## Цель

Преподаватель видит слабые места группы и прогноз готовности каждого к аттестации, с честной
оценкой достоверности. Система сама подбирает следующую карточку под слабые места. Это закрывает
критерии жюри «прогнозирование», «достоверность», «диаграммы».

## Вход

Волна 9 закрыта.

## Задачи

### Бэкенд
- [x] `skill_ratings` по мотивам Elo (PRD 9.7); пересчёт после каждой оценки; тесты (победа над сложным сценарием поднимает рейтинг сильнее, чем над лёгким).
- [x] Адаптивный подбор: слабая группа происшествий, сложность около рейтинга, сначала непройденные; включается в занятии флагом.
- [x] `scripts/simulate_cohort.py`: 300 виртуальных обучающихся со скрытым уровнем, история попыток с шумом, «аттестация» на 20 отложенных попытках.
- [x] `python -m app.domain.analytics.train_readiness`: признаки из PRD, логистическая регрессия с калибровкой, разбиение 80/20, ROC AUC, Brier, калибровочные корзины → `ai/models/readiness_metrics.json` и модель в `ai/models/`.
- [x] `GET /analytics/groups/{id}`: тепловая карта (обучающиеся × группы происшествий × режим), динамика среднего балла и времени, топ-5 типичных ошибок с числом и долей обучающихся, прогноз по каждому с двумя причинами, выжимка (модель или шаблон).
- [x] `GET /analytics/readiness-model`: метрики достоверности.
- [x] `GET /me/progress` полностью: рейтинги, динамика, ошибки, рекомендации.
- [x] Seed: 4 недели истории «Учебной-1» в обоих режимах с правдоподобным разбросом, пометка «демонстрационные данные».

### Фронтенд
- [x] Аналитика группы: тепловая карта (ECharts), линии динамики, список ошибок с выжимкой, таблица прогноза с объяснением и цветом риска, ссылка «Достоверность прогноза».
- [x] Страница «Достоверность прогноза»: AUC, Brier, калибровочный график, объяснение простыми словами, как получены данные.
- [x] Мой прогресс обучающегося полностью.
- [x] На каждом графике подписи осей, период, объём данных; читается в обеих темах.

## Проверка

```bash
python scripts/simulate_cohort.py && python -m app.domain.analytics.train_readiness
pytest backend/tests/domain/analytics -q
```

- [x] Метрики напечатаны и сохранены; AUC на отложенной выборке не ниже 0.75 (если ниже, признаки дорабатываются, числа не правятся руками).
- [x] Тепловая карта и прогноз отображаются на seed-истории; пустая группа показывает понятное пустое состояние.
- [x] Адаптивный подбор: обучающемуся с провалом по «газу» следующая карточка из «газа» (тест).

## Показать

Аналитика «Учебной-1», прогноз для двух обучающихся с объяснением, страница достоверности.

## Если не получается

Выжимка моделью (P2), шаблон обязателен. Калибровочный график (P2), числа обязательны.
