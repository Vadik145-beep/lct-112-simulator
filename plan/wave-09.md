# Волна 9. Кабинеты: отчёты, экспорт, администратор

**Срок:** 22-23.09. **PRD:** разделы 3, 13.7 (администратор), 11 (admin), 14.

## Цель

Продукт можно отдать заказчику: администратор заводит пользователей и службы, следит за системой,
делает копии; преподаватель получает отчёты в PDF и XLSX, меняет оценку с записью в аудит,
комментирует.

## Вход

Волна 8 закрыта.

## Задачи

### Преподаватель
- [x] `PATCH /attempts/{id}/evaluation` с обязательной причиной, запись в `evaluation_overrides` и `audit_log`; в разборе старая оценка зачёркнута, причина видна.
- [x] `POST /attempts/{id}/comments`, показ обучающемуся.
- [x] Экспорт отчёта: PDF (WeasyPrint, встроенные шрифты, кириллица), XLSX (openpyxl), CSV; фоновая задача, если дольше 2 с.
- [x] Отчёт дополнен: замечания по каждой попытке, отличие времени от норматива, грамотность, как в ТЗ («информация о действиях, замечаниях, времени заполнения, отличии от нормативного, грамматике»).
- [x] Мой прогресс обучающегося: балл по занятиям, время, частые ошибки, рекомендации (базово, полностью в волне 10).

### Администратор
- [x] Пользователи: список (ФИО скрыто до «Показать», действие пишется в аудит), создание с ролью и службой, блокировка, сброс пароля (с `must_change_password`), SIP-учётка для обучающегося; тесты: администратор не меняет оценку (403), не правит сценарий (403).
- [x] Службы: список, включение оповещения через АРМ-112, флаг `no_reject`.
- [x] Состояние системы: плитки сервисов (backend, worker, postgres, redis, languagetool, asterisk, llm, stt), нагрузка CPU и память, активные занятия и звонки, оповещения `admin_notifications` (падение сервиса, недоступный провайдер) с подтверждением.
- [x] Журнал аудита: фильтры по пользователю, действию, дате; «Проверить целостность» (`POST /admin/audit/verify`).
- [x] Резервные копии: сервис `backup` (`pg_dump` по крону 03:00, хранение 14 копий, плюс `storage/`), список, «Сделать копию сейчас», `scripts/restore_test.sh` восстанавливает в отдельную базу.
- [x] Настройки: телефония (адрес ARI, кодеки, запись), уровень журналирования, расписание и хранение копий, порог «Не завершено».
- [x] Ограничение: у администратора нет кнопок вмешательства в идущее занятие; тест.

### Безопасность
- [x] Заголовки nginx (HSTS, CSP без внешних источников, X-Frame-Options), CORS только свой origin, куки `Secure`, `SameSite`.
- [x] Тест подмены записи аудита: `verify` находит разрыв цепочки.

## Проверка

```bash
pytest backend/tests/api/test_admin.py backend/tests/api/test_overrides.py backend/tests/reports -q
scripts/restore_test.sh
npx playwright test e2e/admin.spec.ts
```

- [x] PDF скачивается, текст извлекается и содержит кириллицу (тест через pypdf).
- [x] Изменение оценки без причины отклоняется; с причиной пишется аудит и видно обучающемуся.
- [x] Бэкап создаётся и восстанавливается скриптом; после восстановления вход работает.
- [x] Остановленный LanguageTool даёт оповещение администратору, оценка продолжает работать.
- [x] Нового обучающегося, заведённого администратором, можно назначить в группу и провести занятие в обоих режимах.

## Показать

Путь «администратор завёл пользователя → преподаватель добавил в группу → занятие → отчёт PDF».

## Если не получается

Плитка нагрузки CPU (P2). Настройки телефонии можно оставить только чтением (P2). Бэкапы и аудит обязательны.
