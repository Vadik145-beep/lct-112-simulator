# Волна 4. Занятие целиком: преподаватель и обучающийся

**Срок:** 18.09 до 12:00. **PRD:** разделы 13.7 (преподаватель: занятия, мониторинг), 12.

## Цель

Преподаватель сам создаёт и запускает занятие в режиме карточек, видит обучающихся вживую,
завершает и видит результаты. Этого хватает, чтобы показать экспертам 18.09 живой продукт.

## Вход

Волна 3 закрыта.

## Задачи

### Бэкенд
- [ ] `groups`, `group_members`; `GET/POST /groups`, `PATCH /groups/{id}`.
- [ ] `GET/POST /sessions`, `GET/PATCH /sessions/{id}`, `POST /sessions/{id}/start`, `/finish`; преподаватель видит только свои.
- [ ] Выдача карточек группе при старте; источник `generated` (утверждённые сценарии), адаптивный подбор пока случайный по группе происшествий и сложности.
- [ ] `GET /sessions/{id}/report` (JSON): по обучающимся попыток, средний балл, среднее время, отклонение от норматива, неверные решения, типичные ошибки, грамотность; разворот до попыток.
- [ ] События `session.started`, `session.finished`, `attempt.progress` для преподавателя.
- [ ] Тесты доступа: чужое занятие 403, обучающийся не создаёт занятие.

### Фронтенд: преподаватель
- [ ] Список занятий (дата, группа, режим, статус, средний балл).
- [ ] Создание занятия: режим (пока только карточки, приём вызова неактивен до волны 7), группа, группы происшествий (множественный выбор из классификатора), сложность, профиль службы, норматив, порог, подсказки, число карточек на обучающегося.
- [ ] «Начать занятие», «Завершить занятие».
- [ ] Живой мониторинг: сводка, плитки (имя, статус, таймер текущей карточки, последний балл), выделение превышений и низких баллов, клик открывает попытку в режиме просмотра, плашка «Связь потеряна, переподключаемся».
- [ ] Отчёт о занятии: таблица, разворот до попыток со ссылкой на разбор. Экспорт и изменение оценки в волне 9.
- [ ] Группы: список и состав.

### Фронтенд: общее
- [ ] Кабинеты адаптивны до 390 px (мониторинг в одну колонку).

## Проверка

```bash
pytest backend/tests/api/test_sessions.py -q
npx playwright test e2e/teacher.spec.ts
```

- [ ] e2e с двумя контекстами: `teacher1` создаёт занятие и запускает → у `student1` карточка в журнале меньше чем за 2 с → действие обучающегося видно на плитке меньше чем за 2 с → завершение → строка в отчёте.
- [ ] Мок на 20 обучающихся с событиями раз в секунду: мониторинг не тормозит, после обрыва догоняет.
- [ ] `teacher2` не видит занятие `teacher1` (403).

## Показать: репетиция для 18.09

Сквозной прогон вдвоём на двух ноутбуках: Вадим преподаватель, Константин обучающийся. Три
карточки, одна не по профилю, одна просрочена. Отчёт. Засечь время, уложиться в 5 минут.
Записать экран на всякий случай.

## Если не получается

Мониторинг можно показать без плиток, таблицей (P2). Отчёт без разворота (P2). Создание занятия
обязательно.
