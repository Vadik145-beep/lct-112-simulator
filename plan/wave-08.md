# Волна 8. Сценарии: билеты, генерация, реплики, утверждение

**Срок:** 21-22.09. **PRD:** раздел 9.6, 13.7 (сценарии).

## Цель

Преподаватель управляет содержанием: все 96 ситуаций из билетов превращены в сценарии, новые
сценарии создаются одной фразой, реплики заявителя генерируются, озвучиваются и утверждаются,
грамотность проверяется. Тренажёр перестаёт зависеть от seed.

## Вход

Волна 7 закрыта. Профиль `ai` с `llm-gen`.

## Задачи

### Бэкенд
- [ ] JSON Schema сценариев обоих режимов (`app/domain/scenarios/schema_*.json`), валидация Pydantic.
- [ ] `GenerationProvider` (llama.cpp 7B) и шаблонный запасной; RAG по памятке и билетам (`reference_chunks`, e5).
- [ ] Генерация из билета: для каждой из 96 ситуаций черновики обоих режимов (`source=organizers`, `review`): лист фактов, реплики, эталон через классификатор и `resolve_services`; ловушки из PRD 8.3 определяются правилами (регион, описательный адрес, несколько служб, срыв звонка).
- [ ] Генерация по фразе: `POST /scenarios/generate` → `jobs`, прогресс; коды признаков и служб проверяются по справочникам, выдуманные отклоняются; до 2 повторов при невалидном JSON.
- [ ] `POST /scenarios/{id}/revise` (переделка по комментарию, новая версия), `PUT /scenarios/{id}`, версии.
- [ ] Реплики: `PUT /scenarios/{id}/replies/{reply_id}`, `POST …/replies/approve` (частями), `POST …/replies/{reply_id}/audio` (загрузка своей записи), озвучка Piper при утверждении в фоне.
- [ ] `POST /grammar/check`; при утверждении с непросмотренными ошибками требуется подтверждение.
- [ ] `POST /scenarios/{id}/preview-dialog`: поговорить с заявителем до утверждения (текстом).
- [ ] Карточки обучающихся: сохранённая карточка из приёма вызова → сценарий `card_response` (`source=student`) после утверждения; источники занятия `generated` / `student_made` / `mixed`.
- [ ] `POST /reference/docs`: загрузка pdf/docx/txt в справочник и RAG.

### Фронтенд: сценарии
- [ ] Таблица с фильтрами (режим, группа происшествий, источник, статус, билет), поиск.
- [ ] Карточка сценария: лист фактов, эталон (для приёма вызова путь признаков и службы с подсветкой), реплики с плеером, статусом «утверждена / на утверждение», правкой и загрузкой записи; «Поговорить с заявителем»; «Проверить грамотность» с подчёркиванием; поле «Что исправить» и «Переделать»; версии со сравнением; «Утвердить» целиком или отмеченное.
- [ ] Генерация по фразе с формой (режим, тип из дерева, сложность, персонаж, шум) и прогрессом.
- [ ] Загрузка методических материалов.

### Данные
- [ ] Все 96 ситуаций сгенерированы; 20 проверены и утверждены командой (10 + 10), остальные в `review`.

## Проверка

```bash
pytest backend/tests/domain/scenarios backend/tests/api/test_scenarios.py -q
python -m app.scripts.generate_from_tickets --all
```

- [ ] Без профиля `ai` шаблонная генерация даёт валидный сценарий быстрее 2 с.
- [ ] С профилем `ai` фраза «пожар в подземном паркинге, звонит ребёнок» даёт валидный сценарий быстрее 120 с; переделка по комментарию создаёт версию 2; утверждённые реплики не изменились.
- [ ] Для утверждённых реплик есть MP3 и WAV.
- [ ] Сценарий с ошибкой в комментарии эталона подсвечивается при проверке грамотности.
- [ ] Занятие с источником `student_made` выдаёт карточку, созданную обучающимся.

## Показать

Генерация по фразе на экране, прослушивание реплик, правка одной, переделка, утверждение. Потом
занятие с только что утверждённым сценарием.
