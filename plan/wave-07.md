# Волна 7. Приём вызова от звонка до разбора

**Срок:** 20-21.09. **PRD:** разделы 13.5, 13.6, 9.3.

## Цель

Второй режим работает целиком: звонок, разговор с заявителем, заполнение адреса и опросной карты
кнопками-признаками, службы подставляются сами, сохранение, разбор со стенограммой и записью.
Преподаватель может создать занятие в этом режиме.

## Вход

Волны 5-6 закрыты. Скриншот карточки оператора (стр. 15) в `docs/reference/arm112/`.

## Задачи

### Бэкенд
- [ ] Выдача попытки `call_intake`: originate (или браузерный путь), `answered_at`, таймер разговора.
- [ ] `PUT /attempts/{id}/draft` (не чаще раза в 2 с), `POST /attempts/{id}/submit` (идемпотентно по `client_submission_id`), оценка режима приёма вызова, событие `attempt.evaluated`.
- [ ] Автоподстановка служб: при изменении пути признаков и флагов `resolve_services`, ручное добавление службы, удалить нельзя.
- [ ] Занятие в режиме приёма вызова: источник сценариев, `dialog_mode`, `voice_enabled`.
- [ ] Seed: 10 сценариев `call_intake` из фикстур волны 2 с репликами и озвучкой (озвучка скриптом, если генерация ещё не готова: реплики руками).

### Фронтенд: карточка оператора 112 (по скриншоту стр. 15)
- [ ] Верх: панель вызова с софтфоном, АОН из вызова, предоставленный телефон, телефон на месте, «Происшествие №», крупный таймер разговора.
- [ ] Слева: заявитель (ФИО, статус), адрес по полям с подсказкой улиц и автоподстановкой округа и района, описательный адрес, «очистить адрес», «Описание со слов заявителя» со счётчиком 0/1999.
- [ ] Справа: кнопки-флаги, оранжевые «нет контакта» и «срыв звонка», «добавить тип происшествия», опросная карта: панель «Происшествие N» с рядами кнопок по уровням из `/classifier/tree`, выбранные синим, путь можно менять.
- [ ] Низ: оранжевая полоса «Службы» с автоподстановкой, «+», «сохранить».
- [ ] Учебная панель: стенограмма разговора (реплики заявителя и оператора, темы), индикаторы «заявитель говорит» и «слушаю вас», поле текстового ввода при выключенной телефонии, подсказка «Что выяснить» при `hints_enabled`, норматив.
- [ ] Горячие клавиши: `Ctrl+Enter` сохранить, `Tab` в естественном порядке, `?`.
- [ ] Черновик в `localStorage` и на сервере; восстановление после перезагрузки посреди звонка (звонок при этом продолжается).

### Фронтенд: разбор приёма вызова
- [ ] Опросная карта с подсветкой верных и неверных признаков, адрес рядом с эталоном, службы против эталона, обязательные вопросы (выяснены / нет), стенограмма с аудио записи, время, ошибки, грамотность, комментарий ИИ.

### Преподаватель
- [ ] В создании занятия режим «Приём вызова» активен; мониторинг показывает состояние звонка.

## Проверка

```bash
npx playwright test e2e/call_intake.spec.ts
pytest backend/tests/api/test_call_intake.py -q
```

- [ ] e2e (телефония через браузерный путь в CI): попытка → ответ → вопрос «адрес» → реплика → заполнение адреса и признаков → службы подставились → сохранение → разбор с баллом и выясненными темами.
- [ ] Руками с Asterisk: тот же путь голосом.
- [ ] Ситуация «бросил трубку»: заявитель кладёт трубку, обучающийся жмёт «срыв звонка», оценка засчитывает; без отметки срабатывает `dropped_call_unmarked`.
- [ ] Ситуация из другого региона: детектор `region_not_checked`, если регион не уточнён.
- [ ] Перезагрузка страницы посреди звонка не теряет черновик.

## Показать

Полный звонок с гарнитурой на камеру, потом разбор. Сравнить карточку со скриншотом стр. 15.

## Если не получается

Опросная карта из полного дерева тяжёлая: показывать только группу и два уровня, третий уровень (P2).
Подсказка улиц (P2), но округ и район должны подставляться хотя бы для улиц из билетов.
