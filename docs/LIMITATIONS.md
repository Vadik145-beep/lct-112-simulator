# Условия и ограничения

Честный перечень того, что система делает, чего не делает и при каких условиях работает. Написан
для эксперта, который будет проверять решение.

## 1. Назначение

Это **учебный тренажёр**. Он:

- не обрабатывает реальные экстренные вызовы;
- не содержит функционала настоящей системы-112, а лишь имитирует её рабочие процессы и внешний
  вид;
- не связан с реальными службами и не отправляет им никакой информации;
- не работает с персональными данными граждан: все ситуации учебные, из билетов заказчика или
  созданные преподавателем.

## 2. Работа без внешних сетей

Во время занятий система не обращается в интернет: модели, телефония, база и интерфейс находятся
внутри контура. Шрифты, стили и библиотеки поставляются вместе с приложением.

Интернет нужен только на этапе подготовки: собрать образы и один раз скачать модели. Для установки
в изолированном контуре предусмотрен перенос образов и моделей на носителе.

Если в настройках указать внешний адрес модели, не включив явное разрешение, приложение не
запустится и сообщит причину.

## 3. Ограничения искусственного интеллекта

- **Заявитель говорит утверждённое.** В основном режиме модель не сочиняет текст, а выбирает
  реплику из набора, утверждённого преподавателем. Это даёт предсказуемость и скорость, но
  разговор ограничен подготовленными темами: на неожиданный вопрос заявитель отвечает «не знаю» или
  просит повторить.
- **Свободная генерация медленнее.** На сервере без видеокарты свободный ответ занимает несколько
  секунд. Режим оставлен как настраиваемый, но основным на минимальной конфигурации не является.
- **Распознавание речи ошибается** на именах, номерах домов и при плохом микрофоне. Обучающийся
  может задать вопрос текстом, а преподаватель видит стенограмму и может поправить оценку.
- **Оценка текста приблизительна.** Смысловая близость к эталону это оценка, а не истина: итоговый
  балл преподаватель вправе изменить, указав причину, изменение фиксируется в журнале.
- **Выжимки по группе** строятся по шаблону из уже посчитанных показателей, новых фактов они не
  добавляют. Текстовый комментарий к оценке модель не пишет: разбор состоит из составляющих,
  найденных ошибок и эталона.
- **Режим кнопок** (вопросы списком вместо разговора) существует только для запуска на слабой
  машине и не является способом выполнения требования об имитации вызова.

## 4. Ограничения телефонии

- Задержка голоса до 150 миллисекунд достигается в локальной сети; через интернет она выше.
- Через браузер используется широкополосный кодек, при подключении настольного аппарата качество
  зависит от его кодеков.
- Подключение внешнего оператора связи возможно как дополнительная возможность для показа, по
  умолчанию выключено и в закрытом контуре не используется.

## 5. Ограничения данных

- Учебные ситуации взяты из билетов заказчика; часть из них распознана автоматически со сканов,
  распознанные строки помечены и проверялись вручную.
- Справочник улиц ограничен Москвой и происходит из открытого источника.
- Коды сценариев реагирования из классификатора используются как признак похожих происшествий:
  расшифровка этих кодов заказчиком не предоставлена.

## 6. Что не реализовано

| Требование | Состояние |
|---|---|
| Второй фактор аутентификации | не реализован, вход по логину и паролю с ограничением попыток |
| Интеграция с внешним каталогом учётных записей | вынесена в отдельную задачу |
| Пакетное обновление сценариев одним файлом | не реализовано, сценарии создаются и правятся в интерфейсе |
| Карточка оператора 112 один в один с живой системой | сделана как имитация для тренировки приёма вызова: строка «что случилось?», опросная карта по классификатору, статусы заявителя, окно «Пострадавшие», подтверждение сохранения, автоподбор служб. Нет: ~50 опросных карт с вопросами-строками (у нас дерево классификатора и один тип на карточку), горячих клавиш Alt+…, связей «Совпадение» между карточками, карты и координат. Целевая роль тренажёра по уточнению заказчика — диспетчер ДДС, карточку оператора 112 обучающемуся формирует система |
| Мобильная версия эмулятора АРМ-112 | рассчитан на компьютер и планшет; кабинеты преподавателя, администратора и прогресс обучающегося работают на телефоне |
| Отказоустойчивый кластер | предусмотрено разнесение по узлам и автоматический перезапуск сервисов, горячего резерва нет |

## 7. Условия эксплуатации

- Минимальная конфигурация сервера указана в инструкции по установке; при меньших ресурсах
  отключается профиль моделей, и заявитель отвечает заранее озвученными репликами.
- Эталонные сценарии озвучены студийно (записи поставляются вместе с данными); реплики
  сценариев, созданных или изменённых на сервере заказчика, озвучиваются встроенным синтезом
  Piper, без эмоциональной окраски.
- Резервное копирование выполняется ежесуточно, восстановление проверяется скриптом.
- Журнал аудита не допускает изменения и удаления записей; целостность проверяется по цепочке
  контрольных сумм.
- Для работы браузерного софтфона нужен доступ к микрофону и современный браузер.
