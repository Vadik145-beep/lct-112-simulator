# Тренажёр оператора ДДС-112

Учебный тренажёр для операторов 112 и диспетчеров ДДС Москвы. ИИ играет заявителя
и службы, система оценивает действия. Хакатон «Лидеры цифровой трансформации 2026»,
задача №9, команда «Ультратех».

Два режима занятий: **реагирование на карточку** (диспетчер ДДС принимает карточку в журнале,
звонит в службы и ведёт статусы) и **приём вызова** (оператор 112 принимает звонок заявителя,
роль которого играет ИИ, и заполняет карточку). Преподаватель ведёт занятия и получает отчёты,
администратор управляет пользователями. Тренажёр может работать в закрытом контуре без
доступа в интернет.

## Установка у себя

Выберите свой случай:

| Где будет работать тренажёр | Что делать |
|---|---|
| Сервер или компьютер **с интернетом** | [Вариант А](#вариант-а-сервер-с-интернетом) — одна команда `./start.sh` |
| Сервер **без интернета** (закрытый контур) | [Вариант Б](#вариант-б-сервер-без-интернета) — готовим поставку на компьютере с интернетом и переносим на сервер |

### Что нужно

- Linux (Ubuntu 22.04 или 24.04). На Windows и macOS скрипты установки не запускаются:
  откройте готовый сервер или поставьте тренажёр на Linux-сервер (подойдёт и виртуальная машина).
- Память от 16 ГБ, лучше 32 ГБ. Процессор от 6 ядер.
- Место на диске: около 40 ГБ.
- **Docker** (с `docker compose`) и **Git**. Проверка: `docker compose version` и
  `git --version`. Если команда не найдена — Docker по
  [официальной инструкции](https://docs.docker.com/engine/install/ubuntu/), Git:
  `sudo apt install -y git`. На сервере без интернета Git не нужен, Docker ставится
  заранее из пакетов вашего дистрибутива.

### Где вводить команды

Все команды ниже вводятся в **терминале**: на самой машине откройте «Терминал»
(в Ubuntu — Ctrl+Alt+T) или подключитесь к ней по SSH. После `cd lct-112-simulator`
все команды выполняются в этой папке.

### Вариант А. Сервер с интернетом

**1. Скачать тренажёр**

```bash
git clone https://github.com/Vadik145-beep/lct-112-simulator.git
cd lct-112-simulator
```

**2. Запустить одной командой**

> [!WARNING]
> **Нужен интернет.** `start.sh` скачивает нейросети (около 9 ГБ). Без них тренажёр
> запустится урезанным: обучающийся не сможет говорить голосом, заявитель будет хуже
> понимать вопросы. Нет интернета на сервере — смотрите вариант Б.

```bash
./start.sh
```

Скрипт сам скачает нейросети с нашего Google Диска, соберёт и запустит тренажёр с теми же
настройками, что на готовом сервере. Первый запуск занимает **от 30 минут до часа**.
В конце он напечатает адрес, логины и пароль.

**Если нейросети не скачались автоматически** — скачайте их сами одним из двух способов
и снова запустите `./start.sh`: он увидит, что нейросети на месте, и продолжит.

- *Способ 1 — архив с нашего Google Диска вручную.* Откройте в браузере
  https://drive.google.com/drive/folders/1LcqZ0oLFx0nW0yvheWNXchVTo3F6v-Jp, скачайте
  `models.tar` (8,6 ГБ), положите в папку `lct-112-simulator` и в терминале, в этой папке:
  ```bash
  tar -xf models.tar && rm models.tar
  ```
- *Способ 2 — с официальных сайтов нейросетей* (Hugging Face, Silero). В терминале, в папке
  `lct-112-simulator`:
  ```bash
  ./scripts/fetch_models.sh
  ```
  Команда сама проверит, что файлы целые. Если связь оборвётся, запустите её ещё раз —
  она докачает.

Проверить, что нейросети на месте: `ls models/llm` должен показать файлы `qwen2.5-…gguf`.

Дальше — [вход](#вход-после-установки).

### Вариант Б. Сервер без интернета

Всё, что нужно скачать, скачивается заранее на **любом компьютере с интернетом** (Linux,
Docker, Git, около 25 ГБ свободного места). Потом готовая папка переносится на сервер, и там
ничего не скачивается.

**На компьютере с интернетом:**

```bash
git clone https://github.com/Vadik145-beep/lct-112-simulator.git
cd lct-112-simulator
./scripts/fetch_models.sh                   # нейросети (или models.tar с Google Диска, как в варианте А)
./scripts/offline_bundle.sh --with-models   # готовая поставка в папке offline-bundle (~11 ГБ)
```

Перенесите папку `offline-bundle` на сервер: флешкой, внешним диском или по локальной сети.

**На сервере без интернета** (нужен только Docker), в терминале:

```bash
cd offline-bundle
sudo ./install.sh
```

Установщик проверит, что файлы не повреждены при переносе, установит тренажёр в
`/opt/lct/app` с настройками готового сервера и в конце напечатает адрес, логины и пароль.
Подробности — [docs/INSTALL.md](docs/INSTALL.md), раздел 6.

### Вход после установки

Откройте в браузере адрес, который напечатал `start.sh` или `install.sh`, например
`https://192.168.1.50`.

Браузер предупредит «Подключение не защищено» — это нормально, у тренажёра свой
сертификат. Нажмите **«Дополнительные»** → **«Перейти на сайт»**. Чтобы предупреждения не
было, установите на рабочие места корневой сертификат тренажёра. Взять его можно командой
`docker compose cp nginx:/etc/nginx/certs/ca.crt .` в папке установки (`lct-112-simulator`
в варианте А, `/opt/lct/app` в варианте Б).

| Роль | Логин | Пароль |
|---|---|---|
| Преподаватель | `teacher` | `12345678` |
| Обучающийся | `student` | `12345678` |
| Администратор | `admin` | `12345678` (при первом входе попросит сменить) |

После установки занятий и групп нет: преподаватель создаёт группу, добавляет в неё
`student` и назначает занятие. Пароли `teacher` и `student` поменяйте через администратора;
пароль для новой установки можно задать заранее переменной `SEED_PASSWORD` в `.env`.

## Если что-то не работает

| Что видите | Что сделать |
|---|---|
| `docker: command not found` или `permission denied` | Docker не установлен или нужны права: `sudo ./start.sh` (или `sudo ./install.sh`) |
| `port is already allocated` | Порт 80 или 443 занят. В файле `.env` поставьте `HTTP_PORT=8080` и `HTTPS_PORT=8443`, запустите снова, откройте адрес с `:8443` |
| Страница не открывается сразу | Подождите 2–3 минуты и обновите: нейросети ещё загружаются |
| Не хватает памяти, всё зависает | Нужно от 16 ГБ |
| Нейросети не скачались | Вариант А, «Если нейросети не скачались автоматически». Если не вышло — откройте готовый сервер |

Проверить, что система жива: `https://<адрес>/health` → `"status":"ok"`.
